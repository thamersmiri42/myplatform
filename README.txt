LOCAL PREVIEW
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. Test language switching (EN → FR → AR), theme toggle, the cinematic intro, Ctrl/⌘+K quick navigation, certificate search/filters, expandable project notes, and the CV/document links.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository for the portfolio.
2. Upload the CONTENTS of this folder into the repository root (not the ZIP itself).
3. Open Settings → Pages.
4. Choose Deploy from a branch → main → /(root) → Save.
5. Wait for GitHub Pages to finish deployment, then test the public URL on a phone and desktop.

NO BUILD STEP REQUIRED
The site uses plain HTML, CSS, and JavaScript. It does not require npm, a framework, or a build command. Google Fonts are optional; system fallbacks are included.

BEFORE PUBLIC SHARING
- Set the final public site URL in a canonical link and use an absolute public URL for og:image/twitter:image once the GitHub Pages address is known. The deployment URL was intentionally not guessed.
- Verify the repository/demo links for projects and update each project description with screenshots of features that are genuinely implemented.
- Learning notes beneath certificates are concise takeaways inferred from the document titles and visible certificate/event details. Where a document is a participation attestation rather than a course certificate, the note is framed as a takeaway from participation. Adjust any note if the exact programme syllabus covered different topics.
- The site intentionally does not invent public demos, project metrics, or credential IDs.
